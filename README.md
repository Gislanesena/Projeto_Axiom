## 🧠 Sobre o projeto
O Projeto AxiomCode tem como príncipio fornecer aos calouros de tecnologia um ambiente acolhedor e agradável para inspirar e apoiar até o final do curso.


## ⚙️ Tecnologias utilizadas
- C#
- HTML
- CSS
- JS
- Docker
- PostgreSQL

---

## 🛠️ Funcionalidades
- Google Forms para métricas de desistência em pró de entender o problema e fornecer uma resolução
- Página de eventos disponíveis para inscrição
- Página de Contato para Feedback, sugestões e solicitação de voluntariado no projeto.
