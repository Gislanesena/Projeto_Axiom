AXIOMCODE - POR ONDE COMEÇAR
============================

1. ONDE ESTÁ O ARQUIVO DO BANCO (PostgreSQL)?
   Pasta: DesenvolvimentoWeb \ Backend
   Arquivo: Schema.sql

   O banco usado pelo projeto é PostgreSQL. Credenciais padrão do projeto:
   - Usuario: admin
   - Senha:  123456789
   - Banco:  axiomcode
   - Porta:  5432


2. SUBIR O POSTGRESQL (Docker - recomendado)
   Na pasta onde está docker-compose.yml:
      docker compose up -d

   Depois crie as tabelas (com psql ou pgAdmin / DBeaver), conectando em:
      postgresql://admin:123456789@localhost:5432/axiomcode
   e executando o arquivo Backend\Schema.sql


3. COMO CRIAR O USUÁRIO ADMIN DO SITE?
   NÃO é no PostgreSQL à mão no dia a dia. É no navegador, depois de rodar o programa:

   a) PowerShell ou CMD:
      cd ...\DesenvolvimentoWeb\Backend
      dotnet run

   b) Quando o servidor estiver em http://localhost:5000, abra o navegador em:
      http://localhost:5000/setup

   c) Na página, coloque nome de usuário e senha e crie o primeiro administrador.
      Depois faça login em http://localhost:5000/login
